# Keypad profile marks

Row icons for the built-in keypad profiles of command-line tools, which have no
desktop icon of their own. From lobehub/lobe-icons (`@lobehub/icons-static-svg`
1.95.1, MIT): `claudecode-color.svg` as `claude-code.svg`, `codex-color.svg` as
`codex.svg` (size attributes normalised, titles dropped).

Claude Code is a trademark of Anthropic PBC and Codex of OpenAI. The marks only
identify the tool a profile is made for; JuhRadial MX is not affiliated with
either company.
